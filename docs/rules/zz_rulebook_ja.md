# ZENONZARD ルールブック 日本語版

この文書は、現在の ZZ クローンの基本ルールである。カード個別の裁定はカードテキストを優先し、同じ日本語表現は常に同じ意味として扱う。

## 1. ゲームの目的

各プレイヤーはデッキ40枚とフォース2枚を用いて対戦する。相手のプレイヤーライフを0以下にするか、相手のドローステップで相手がカードを引く時にデッキが0枚である場合、勝利する。

フォースはプレイヤーを守る常時能力または誘発能力を持つ。フォースが残っている間でも、カードやキーワードの効果によってプレイヤーを直接攻撃できる場合がある。

## 2. カードと領域

カード種別は次の通りである。

| 種別 | 説明 |
| --- | --- |
| フィールド・ミニオン | コストを支払い、フィールドに召喚するミニオン。攻撃、ブロック、移動ができる。 |
| ベース・ミニオン | 主にマナとしてベースに置かれるミニオン。移動権でフィールドに移動できる。 |
| マジック | コストを支払い、効果を解決した後にトラッシュに置かれるカード。 |
| 無色マナ | カードではないマナ・トークン。ベースに置かれ、コスト支払いに使える。 |
| フォース | デッキとは別に選ぶ常設カード。ライフと能力を持つ。 |

主な領域は、デッキ、手札、フィールド、ベース、トラッシュ、除外、フォースである。フィールドとベースにあるミニオンのみがアクティブまたはレスト状態を持つ。手札、デッキ、トラッシュのカードはレスト状態を持たない。

## 3. 基本用語

| 用語 | 意味 |
| --- | --- |
| BP | ミニオン同士のバトルで比べる戦闘力。BPは0未満にならない。 |
| DP | プレイヤーやフォースへ与えるダメージ量。DPは0未満にならない。 |
| コスト | カードを使用するために必要なマナ数。色コストとフリーコストを含む。 |
| 色コスト | 指定色のマナで支払う必要があるコスト。 |
| フリーコスト | 任意の色または無色マナで支払えるコスト。 |
| アクティブ | 行動できる縦向き状態。 |
| レスト | 行動済み、または支払いに使用された横向き状態。 |
| 移動権 | 1ターンにミニオンをベースとフィールドの間で移動できる回数。 |
| ミニオン・マナ | ベースに置かれているミニオンカード。無色マナ・トークンは含まない。 |

プレイヤーライフとフォースライフは10を上限とする。回復効果で10を超えることはない。

## 4. デッキ構築とゲーム開始

デッキは40枚ちょうどで構築する。同名カードは通常3枚まで入れられる。ただし、カードテキストに「何枚でもデッキに入れられる」と書かれている場合はその制限を受けない。

各プレイヤーは異なるフォースを2枚選ぶ。同じフォースを2枚選ぶことはできない。

ゲーム開始時、各プレイヤーは手札を6枚引く。その後、マリガンを行う。マリガンでは任意の枚数の手札を戻し、同じ枚数を引き直す。マリガン後、デッキをシャッフルする。

プレイヤーライフの初期値は次の式で決める。

```text
プレイヤーライフ = 12 - 選んだ2枚のフォースの初期ライフ合計
```

例: 初期ライフ2のフォースと初期ライフ3のフォースを選んだ場合、プレイヤーライフは7になる。

## 5. ターンの流れ

ターンは次の順番で進む。

| 手順 | 内容 |
| --- | --- |
| ターン開始 | ターン開始時効果を解決する。通常、そのターンの移動権を1得る。ただし先攻1ターン目は移動権を得ない。 |
| リフレッシュ | 自分のフィールド、ベース、フォースをアクティブにする。召喚酔いも解除する。 |
| ドロー | カードを1枚引く。ただし先攻1ターン目はドローしない。ドローステップでカードを引く時にデッキが0枚である場合、そのプレイヤーは敗北する。 |
| マナ | ベース・ミニオンを1枚ベースに置く、無色マナを1つ置く、または何もしない。 |
| メイン | カードの使用、ミニオンの移動、攻撃、ターン終了を行う。 |
| ターン終了 | ターン終了時効果を解決する。ターン中のみの修正や未使用の移動権は失われる。 |

## 6. マナとコスト支払い

ベースにあるアクティブなカードまたは無色マナをレストしてコストを支払う。レスト状態のマナは支払いに使えない。

色コストは原則として同じ色のマナで支払う。フリーコストは任意の色または無色マナで支払える。

ベースの上限は10枚である。効果やマナステップでベースにカードまたは無色マナを置く時、ベースがすでに10枚ある場合は、置く側ではなくベースを持つプレイヤーが既存のベース1枚を選んで置き換える。置き換えられたカードはトラッシュに置かれる。置き換えられた無色マナ・トークンはゲーム外に置かれる。

## 7. カードの使用と召喚

フィールド・ミニオンは、原則として自分のメインでコストを支払い、フィールドに召喚する。召喚されたターンのミニオンは召喚酔いを持ち、通常はプレイヤーへ攻撃できない。

ベース・ミニオンは、原則としてマナステップで手札からベースに置く。ベース・ミニオンを通常の召喚として直接フィールドに出すことはできない。

マジックは、指定されたタイミングでコストを支払い、効果を解決した後にトラッシュに置く。フラッシュで使用できるマジックは、フラッシュタイミングにも使用できる。

フィールドの上限は5体である。フィールドにミニオンを出す時、フィールドがすでに5体いる場合は、フィールドを持つプレイヤーが既存のミニオン1体を選んで置き換える。置き換えられたミニオンはトラッシュに置かれる。

## 8. 移動

自分のメインで移動権を1消費し、ミニオンをベースからフィールド、またはフィールドからベースへ移動できる。通常の移動権は1ターンに1回である。

ベースにあるベース・ミニオンはフィールドへ移動できる。フィールドにあるミニオンはベースへ移動できる。無色マナ・トークンはフィールドへ移動できない。トークン・ミニオンは通常の移動権では移動できない。

移動したミニオンは、移動前のアクティブまたはレスト状態を保つ。レストしているミニオン・マナをフィールドへ移動した場合、そのミニオンはレスト状態のままフィールドに出る。

## 9. 攻撃とブロック

自分のメインで、アクティブな自分のフィールド・ミニオンをレストして攻撃できる。先攻1ターン目は攻撃できない。

通常の攻撃対象は、相手のフォースまたは相手プレイヤーである。通常アクションとして相手ミニオンへ直接攻撃することはない。カード効果が別途指定する場合のみ、その効果に従う。

相手のフォースが残っている間、召喚酔いを持つミニオンは通常プレイヤーを攻撃対象に選べない。フォースがすべて破壊されている場合、またはキーワードや効果が許可する場合は、プレイヤーを攻撃対象に選べる。

攻撃宣言後、フラッシュタイミングに入る。防御側から優先権を持ち、互いに続けてパスするまでフラッシュで使用できるカードや能力を使える。

フラッシュ終了後、防御側はブロック可能なアクティブ・ミニオン1体でブロックできる。ブロックしたミニオンはレストする。ブロックしない場合、攻撃はそのまま攻撃対象へ進む。

ブロックされた場合、攻撃ミニオンとブロックミニオンのBPを比べる。BPが相手以上なら相手ミニオンを破壊する。双方のBPが互い以上なら双方を破壊する。

ブロックされなかった場合、攻撃ミニオンのDPに等しいダメージを攻撃対象のフォースまたはプレイヤーに与える。

## 10. ダメージ、破壊、ドロー

フォースにダメージが与えられた場合、そのフォースのライフを減らす。フォースのライフが0以下になった場合、そのフォースは破壊され、レスト状態で破壊済みとして扱う。

フォースが破壊された時、そのフォースの破壊時効果を解決する。基本フォースは共通して、自分のデッキからベース・ミニオンカード1枚を選び、ベースに置く。その後、デッキをシャッフルし、カードを1枚引く。置かれたベース・ミニオンの配置時効果は原則として発揮しない。

手札の上限は10枚である。手札が10枚の状態でカードを引く場合、引いたカードは手札に加えずトラッシュに置く。

カード効果でカードを引く場合、デッキが0枚でも敗北条件にはならない。引けないカードは引かない。

## 11. 対象選択と任意効果

「選ぶ」と書かれている効果は、指定された対象を選んで解決する。対象が存在しない場合、その対象を必要とする効果は解決できないか、可能な範囲のみ解決する。カードを使用できるかどうかはカードテキストとタイミングに従う。

「できる」と書かれている効果は任意である。選ばないことを選択した場合、その部分は解決しない。

「N体まで」「N枚まで」と書かれている場合、0からNまでの任意の数を選べる。たとえば「2体まで選ぶ」は、0体、1体、2体のいずれも適正である。

「1体を選ぶ」「2枚を選ぶ」のように数が固定されている場合、原則としてその数を選ぶ。十分な対象がない場合は、カードテキストの「できる」や「最大」「まで」の有無に従う。

プレイヤーを対象にできる効果では、プレイヤー自身を明確な対象として選択できる必要がある。フォースを対象にできる効果では、各フォースを個別に対象として選択できる必要がある。

## 12. キーワード能力

| キーワード | 効果 |
| --- | --- |
| 再起 | 自分のターン終了時、このミニオンをアクティブにする。 |
| 襲撃 | このミニオンは、場に出たターンでもプレイヤーへ攻撃できる。フォースが残っていても、プレイヤーを攻撃対象に選べる。 |
| 飛来 | このフィールド・ミニオンカードは、フラッシュタイミングにコストを支払って召喚できる。飛来はブロック制限ではない。 |
| 潜入 | このミニオンは、同じコストのミニオンにしかブロックされない。 |
| 奪命 | 自分のターン中、このミニオンがバトルした相手ミニオンをバトル終了時に破壊する。 |
| 貫通 | 自分のターン中、このミニオンがブロックされてバトルに勝った場合、攻撃ミニオンのDPとブロックミニオンのDPの差分を本来の攻撃対象へ与える。フォースを攻撃してDPがフォースの残りライフを上回った場合、余剰ダメージを相手プレイヤーへ与える。 |
| 連携 | 指定された色の自分のマナがこのターンに置かれている場合、手札から使用したこのカードの連携効果を解決する。標準処理はカードを1枚引く。 |
| 加護 | ベースから得られる特殊なマナまたは保護効果を示す用語。カードごとのテキストに従う。 |

キーワードではないが頻出する処理として、「フリーコストを減らす」「BPを増減する」「DPを増減する」「選ばれない」「ダメージを軽減する」がある。これらはカードまたはフォースに付与された状態として扱う。

## 13. フォース共通ルール

フォースはライフと能力を持つ。フォースがアクティブで破壊されていない間、その常時能力または条件付き能力が有効である。フォースがレストしている場合、または破壊されている場合、その常時能力は発揮しない。

自分のリフレッシュで、自分のフォースはアクティブになる。

すべての基本フォースは、破壊時に次の共通効果を持つ。

```text
【破壊時】
自分のデッキからベース・ミニオンカード1枚を選び、ベースに置く。
その後、デッキをシャッフルし、自分はカードを1枚引く。
```
