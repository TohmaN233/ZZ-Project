# ZENONZARD 规则书 中文版

本文是当前 ZZ Clone 的基本规则。单卡裁定优先遵循卡牌文本；相同的日文表述应始终对应相同的规则含义。

## 1. 游戏目的

双方玩家各使用 40 张牌的卡组和 2 张 Force 进行对战。将对手玩家生命降至 0 以下，或在对手的抽卡步骤中，对手需要抽卡而其卡组为 0 张时，即为胜利。

Force 拥有保护玩家的常时能力或诱发能力。即使对手仍有 Force，卡牌或关键词效果也可能允许直接攻击玩家。

## 2. 卡牌与区域

卡牌种类如下。

| 种类 | 说明 |
| --- | --- |
| Field Minion | 支付费用后召唤到 Field 的 Minion。可以攻击、阻挡、移动。 |
| Base Minion | 主要作为 Mana 放置到 Base 的 Minion。可以通过移动权移动到 Field。 |
| Magic | 支付费用并结算效果后放入 Trash 的卡牌。 |
| 无色 Mana | 不是卡牌的 Mana Token。放置在 Base，用于支付费用。 |
| Force | 与卡组分开选择的常设卡。拥有生命和能力。 |

主要区域包括：卡组、手牌、Field、Base、Trash、除外、Force。只有位于 Field 和 Base 的 Minion 具有激活或疲劳状态。手牌、卡组、Trash 中的卡牌没有疲劳状态。

## 3. 基本用语

| 用语 | 含义 |
| --- | --- |
| BP | Minion 之间战斗时比较的战斗力。BP 不会低于 0。 |
| DP | 对玩家或 Force 造成伤害的数值。DP 不会低于 0。 |
| 费用 | 使用卡牌所需的 Mana 数，包括颜色费用和自由费用。 |
| 颜色费用 | 必须用对应颜色的 Mana 支付的费用。 |
| 自由费用 | 可以用任意颜色或无色 Mana 支付的费用。 |
| 激活 | 可以行动的竖置状态。 |
| 疲劳 | 已行动，或已用于支付费用的横置状态。 |
| 移动权 | 每回合可以在 Base 与 Field 之间移动 Minion 的次数。 |
| Minion Mana | 放置在 Base 的 Minion 卡。无色 Mana Token 不包含在内。 |

玩家生命和 Force 生命上限为 10。回复效果不能使其超过 10。

## 4. 卡组构筑与游戏开始

卡组必须正好为 40 张。同名卡通常最多放入 3 张。但是，如果卡牌文本写有「何枚でもデッキに入れられる」，则不受此数量限制。

双方玩家各选择 2 张不同的 Force。不能选择 2 张相同的 Force。

游戏开始时，双方玩家各抽 6 张作为起手。之后进行调度。调度时，可以选择任意数量的手牌放回，并抽取相同数量的牌。调度后洗切卡组。

玩家生命初始值按以下公式决定。

```text
玩家生命 = 12 - 所选 2 张 Force 的初始生命合计
```

例：选择初始生命为 2 的 Force 和初始生命为 3 的 Force 时，玩家生命为 7。

## 5. 回合流程

回合按以下顺序进行。

| 步骤 | 内容 |
| --- | --- |
| 回合开始 | 结算回合开始时效果。通常获得本回合 1 点移动权。但是先攻第 1 回合不获得移动权。 |
| 刷新 | 将自己的 Field、Base、Force 变为激活状态。召唤疲劳也会解除。 |
| 抽卡 | 抽 1 张牌。但是先攻第 1 回合不抽卡。若在抽卡步骤（抽卡阶段）中需要抽卡时卡组为 0 张，该玩家败北。 |
| Mana | 将 1 张 Base Minion 放置到 Base，放置 1 个无色 Mana，或什么也不做。 |
| 主要 | 使用卡牌、移动 Minion、攻击、结束回合。 |
| 回合结束 | 结算回合结束时效果。仅持续到本回合的修正和未使用的移动权会失去。 |

## 6. Mana 与费用支付

将 Base 中激活状态的卡牌或无色 Mana 疲劳，以支付费用。疲劳状态的 Mana 不能用于支付费用。

颜色费用原则上必须由相同颜色的 Mana 支付。自由费用可以由任意颜色或无色 Mana 支付。

Base 上限为 10 张。通过效果或 Mana 步骤向 Base 放置卡牌或无色 Mana 时，如果该 Base 已有 10 张，则由持有该 Base 的玩家选择 1 张既有 Base 进行替换，而不是由放置效果的玩家选择。被替换的卡牌放入 Trash。被替换的无色 Mana Token 放到游戏外。

## 7. 卡牌使用与召唤

Field Minion 原则上在自己的主要阶段支付费用并召唤到 Field。召唤出的回合中，该 Minion 具有召唤疲劳，通常不能攻击玩家。

Base Minion 原则上在 Mana 步骤从手牌放置到 Base。Base Minion 不能作为通常召唤直接放到 Field。

Magic 在指定时机支付费用，结算效果后放入 Trash。可以在 Flash 使用的 Magic，也可以在 Flash 时机使用。

Field 上限为 5 体。向 Field 放置 Minion 时，如果 Field 已有 5 体，则由持有该 Field 的玩家选择 1 体既有 Minion 进行替换。被替换的 Minion 放入 Trash。

## 8. 移动

在自己的主要阶段，可以消耗 1 点移动权，将 Minion 从 Base 移动到 Field，或从 Field 移动到 Base。通常每回合有 1 次移动权。

Base 中的 Base Minion 可以移动到 Field。Field 中的 Minion 可以移动到 Base。无色 Mana Token 不能移动到 Field。Token Minion 不能通过通常移动权移动。

移动后的 Minion 保持移动前的激活或疲劳状态。疲劳状态的 Minion Mana 移动到 Field 时，该 Minion 以疲劳状态进入 Field。

## 9. 攻击与阻挡

在自己的主要阶段，可以将自己 Field 中激活状态的 Field Minion 疲劳并进行攻击。先攻第 1 回合不能攻击。

通常攻击对象为对手 Force 或对手玩家。通常行动不能直接攻击对手 Minion。若卡牌效果另有指定，则遵循该效果。

对手仍有 Force 时，具有召唤疲劳的 Minion 通常不能选择玩家作为攻击对象。若对手所有 Force 均已破坏，或关键词及效果允许，则可以选择玩家作为攻击对象。

攻击宣言后进入 Flash 时机。防御方先拥有优先权，双方可以交替使用可在 Flash 使用的卡牌或能力，直到双方连续放弃为止。

Flash 结束后，防御方可以选择 1 体可阻挡的激活状态 Minion 进行阻挡。进行阻挡的 Minion 疲劳。若不阻挡，攻击直接进入攻击对象。

被阻挡时，攻击 Minion 与阻挡 Minion 比较 BP。若一方 BP 大于或等于对方，则破坏对方 Minion。若双方 BP 都大于或等于对方，则双方同时破坏。

未被阻挡时，对攻击对象的 Force 或玩家造成等同于攻击 Minion DP 的伤害。

## 10. 伤害、破坏、抽卡

Force 受到伤害时，减少该 Force 的生命。Force 生命降至 0 以下时，该 Force 被破坏，并以疲劳状态视为已破坏。

Force 被破坏时，结算该 Force 的破坏时效果。基本 Force 共通效果为：从自己的卡组选择 1 张 Base Minion 卡，放置到 Base。之后洗切卡组，自己抽 1 张牌。以此方式放置的 Base Minion 原则上不发动配置时效果。

手牌上限为 10 张。手牌为 10 张时抽卡，抽到的卡不加入手牌，而是放入 Trash。

通过卡牌效果抽卡时，即使卡组为 0 张也不满足败北条件。无法抽取的卡牌不抽取。

## 11. 对象选择与任意效果

写有「選ぶ」的效果，需要选择指定对象并结算。若不存在对象，则需要该对象的效果不能结算，或只在可能范围内结算。卡牌能否使用，取决于卡牌文本和时机。

写有「できる」的效果为任意效果。选择不执行时，该部分不结算。

写有「N体まで」「N枚まで」时，可以选择 0 到 N 的任意数量。例如「2体まで選ぶ」可以合法选择 0 体、1 体或 2 体。

像「1体を選ぶ」「2枚を選ぶ」这样数量固定时，原则上选择该数量。对象不足时，依照卡牌文本中是否存在「できる」「最大」「まで」处理。

若效果可以选择玩家为对象，则必须能够明确选择玩家本身。若效果可以选择 Force 为对象，则必须能够分别选择各个 Force。

## 12. 关键词能力

| 关键词 | 效果 |
| --- | --- |
| 再起 | 自己回合结束时，将此 Minion 变为激活状态。 |
| 袭击 | 此 Minion 即使在进场的回合也可以攻击玩家。即使对手仍有 Force，也可以选择玩家作为攻击对象。 |
| 飞来 | 此 Field Minion 卡可以在 Flash 时机支付费用并召唤。飞来不是阻挡限制。 |
| 潜入 | 此 Minion 只能被费用相同的 Minion 阻挡。 |
| 夺命 | 在自己的回合中，此 Minion 战斗过的对手 Minion 会在战斗结束时被破坏。 |
| 贯通 | 在自己的回合中，此 Minion 被阻挡并赢得战斗时，将攻击 Minion 的 DP 与阻挡 Minion 的 DP 差值伤害给予原本的攻击对象。攻击 Force 且 DP 超过该 Force 剩余生命时，将溢出伤害给予对手玩家。 |
| 连携 | 若本回合放置过指定颜色的自己的 Mana，则从手牌使用此卡时结算连携效果。标准处理为抽 1 张牌。 |
| 加护 | 表示从 Base 获得的特殊 Mana 或保护效果。依照各卡牌文本处理。 |

不是关键词但经常出现的处理包括：减少自由费用、增减 BP、增减 DP、不会被选择、减轻伤害。这些作为赋予卡牌或 Force 的状态处理。

## 13. Force 共通规则

Force 拥有生命和能力。Force 处于激活且未被破坏时，其常时能力或条件能力有效。Force 处于疲劳状态，或已被破坏时，其常时能力不发挥。

自己的刷新步骤中，自己的 Force 变为激活状态。

所有基本 Force 具有以下共通破坏时效果。

```text
【破坏时】
从自己的卡组选择 1 张 Base Minion 卡，放置到 Base。
之后洗切卡组，自己抽 1 张牌。
```
