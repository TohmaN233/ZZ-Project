# EX02C 实现约定

## 范围与对应表

- 官网 EXCODE:02C SAO 为 68 张；另有 CAMPAIGN 的「SAO」アスナ和「SAO」キリト。
- `data/ex02_ex02c_equivalences.tsv` 记录全部 70 对对应关系。活动卡两行明确标为 CAMPAIGN。
- EX02 与对应 EX02C/SAO 活动卡按用户确认视为同名；合计三张。变形后卡仍不允许构筑或 debug 凭空生成。
- 两套各 70 张卡面均注册，分别在原版 EX:02 与 EX02C/CAMPAIGN 卡包检索；EX02 复用已验证的 EX02C 能力。
- 两版保留各自卡名、原文、翻译和卡图；变形沿本卡面的既有关系，具名检索可选对应卡面，合计三张。
- 具名效果检索也遵守对应关系，例如ソードゴーレム与ヒュージ・スタチュー，不能只修构筑张数。

## スイッチ

用户在 2026-10-22 明确：指定种族的己方 Minion 被召唤时，场上スイッチ卡重触发自身标记的效果，
包括【破壊時】或【自分のターン開始時】标记段落。不是把刚召唤卡的召唤时效果重复一次。

- 按卡面指定种族匹配；保留效果正文自己的条件、目标、时长及强制/可选性。
- 原始时点与スイッチ是同一段效果的两个触发入口；不能把原始破坏时“自身被破坏”条件错误带到スイッチ入口。
- スイッチ只结算那一段效果，不重新召唤能力卡，也不重放变形、其他时点或全部卡面效果。
- 触发时，能力卡必须在其控制者 Field；不响应敌方召唤、从 Base 移动或由效果直接放入场。
- 一次合法召唤对每个符合条件的スイッチ来源按规则排队；多个来源不得覆盖、遗漏或无限递归。
- 加入共享触发与提示路径，并覆盖正例、错误种族、对手召唤、移动/生成、来源离场和多来源。

## 文本与显示

EX02C/上述活动卡没有官方英文版，不创建英文卡名或另行翻译效果。
按用户确认，英文 UI 通过 70 组显式对应关系复用 EX02 已有英文效果；具名检索、自称和变形目标替换为对应 SAO 日文卡名。
共享 `card_translation` 为卡查、对局详情和效果提示提供英文显示文字；保留 SAO 的卡名、卡图、日文及中文，源表不伪造英文印刷版。
中文优先复用用户完成的 AI_translation 与统一译名资料，不重新覆盖已有译名。
卡面来源为本地 `asserts/ZENONZARD_CARDLIST/<颜色>/<card_id>.png` 及官方日文图片链接。
`card_ability_face_verified.tsv` 的人工校正覆盖 OCR，并由共享文本规范化器统一段落。
逐暗者／炎刃狂焰的日文加护条件是费用 3 以上，不限定种族；英文印刷多出的 Sword 限制记录在源表 `official_conflicts`，结算及英文显示按日文处理。

## 接口和验收

每卡在 `zz/ex02c_cards/<card_id>.py` 定义 CARD_ID 与 build_card(row)，使用 `_card_from_row(row, infer_effects=False)`。
需要共享能力时在 shared_change_request 中明确接口，由共享集成节点一次实现；不要逐卡复制规则。
复用 `data/card_transformations.tsv` 的既有三条合作卡变形链。变形卡场景先实际变形再验证，不能绕过 debug 限制。
牌组身份、具名检索、スイッチ和中文显示使用共享路径，并按 ZZ_EXPERIENCE 的适用编号检验。
每卡提供真实 GameSession 正例和边界场景；最终检查 EX02C 70/70 注册、来源费用/属性、68+2 卡表覆盖、
同名合计上限、英文效果复用及既有 PC02R 回归。新版本不能削弱此前确认的加护、容量和可见性合同。
