Game Lobby

组卡到开局皆在游戏大厅

Game Lobby
01

普通人机对战

你控制一方，另一方由所选难度的 AI 与 Codeman 配置驱动。这是最接近普通游玩的一种模式。

  • 创建、保存与编辑卡组
  • 分别选择双方 Codeman 与卡垫
  • 指定先后手与玩家所在侧
01

卡牌对战

处理核心对战流程，并修正效果目标筛选、伤害与 Force 治疗、基地持有者替换和 Bless 返回；弃牌与抽牌会显示动画和增益详情。

02

卡组制作

搜索卡池、检查张数与 Force 配置；同名重印卡合并计算，套牌最多 3 张。

03

Replay

保存最近对局并按事件回看；训练结果可以关联回放，寻找输局中的其他路线。

04

Online

支持同一局域网直连，也支持通过项目维护者的个人服务器建立房间。

AI & Codeman

三档离线AI对手

Easy 是 Greedy CPU；Medium 与 High 使用强化学习训练出的策略。训练规模有限，因此现阶段的定位是可玩的研究与娱乐功能，而不是高水平竞技对手。

当前说明

Greedy CPU

不加载训练模型，依据合法行动与人工启发式权重选择当前看来最有利的动作，运行快，也最容易理解。

关于 AI 水平的诚实说明

作者拥有统计学学位，但没有修读强化学习课程，研究方向也与此无关；模型训练规模同样不大。电脑 AI 的训练数据和卡池目前只覆盖 PC01，PC01R、EX01、PC02、PC02R DIVINE、EX02、EX02C/SAO 没有进入训练流程。当前 AI 与 ZENONZARD 正式运营时期万代使用的 AI 仍有明显差距。相关实现由 Codex 协助编写，并参考了 ygo-agent 的公开方法与工程结构。

CODEMAN MEMORY

每个 Codeman 都有自己的近期对战记忆

对局结束后，系统会在本机保存该 Codeman 最近的一部分战斗记录与回放。若你为某个 Codeman 进行了专门训练，并生成了它自己的 .pt 模型，选择这个对手时会优先加载该专属模型；没有专属模型时则使用公开默认模型。

完成对局→近期记忆→可选训练→.pt

对战时点击自己的 Codeman，可以让 AI 对当前选择给出建议。由于模型能力有限，这更像一个可观察的娱乐助手，而不是可靠教练。

INSTALLATION

下载 v0.5.2；首次启动可自动获取资源

v0.5.2 的 Windows 版将卡组保存在安装目录 data/decks/；首次启动时从旧 AppData 卡组目录迁移，保留原文件备份且不覆盖冲突卡组。换手时选牌不再遮挡邻牌，启动失败会显示诊断信息；为保护数据，卸载时可能保留部分程序资源。仍包含 v0.5.1 的一键重置（已保存卡组不会被删除）以及 v0.5.0 加入的 EX02C/SAO 卡牌。Windows 安装包和 Linux 便携包包含可玩的游戏与默认模型。缺少完整 asserts/ 时，桌面客户端会询问是否下载并安装包含英文卡图的 asserts.7z。

  1. 1
    选择平台发行包

    Windows 使用安装包，Linux 使用便携包；macOS 和开发者使用源码包。自建服务器使用独立联机服务器包。

  2. 2
    首次启动获取资源

    若缺少 asserts/，客户端会询问是否下载 asserts.7z，校验 CRC 后解压到程序目录；包为 1.53 GB，展开后 1.58 GB，请预留 3.2 GB。包含英文卡图；取消后不启动，失败可重试。

  3. 3
    源码版本安装依赖

    Windows 安装包不需要 Python 或 Node.js；源码启动才需要 Python 3.10+、Node.js 20+ 与 npm install。

  4. 4
    启动客户端

    Windows 安装包从开始菜单或桌面快捷方式启动；Linux bundle 解压后运行 ./launch-electron.sh；源码版本使用 .cmd、.sh 或 npm run electron:dev。
